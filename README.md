# pixel.fireflyzero.com

A dead simple web editor for pixel art (re-)designed specifically for [Firefly Zero](https://fireflyzero.com/).

Give it a try: [pixel.fireflyzero.com](https://pixel.fireflyzero.com/).

This is a fork of the amazing [pixel-editor](https://github.com/lospec/pixel-editor) by the [Lospec](https://lospec.com/) team. The original version is, unfortunately, unmaintained, so we decided to host our own fork. The fork mostly removes features to declutter UI and fit Firefly Zero limitations.
